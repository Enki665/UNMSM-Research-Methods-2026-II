# 04_Literature_Review_PRISMA

Protocolo de revisión sistemática según PRISMA 2020 (Sesión 4) sobre gemelos digitales y agentes de IA para el monitoreo de equipos mineros, con una corrida preliminar de búsqueda documentada (73 registros identificados, 24 únicos evaluados, 3 estudios primarios incluidos), registro completo de búsqueda y análisis de brechas.
